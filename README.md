# TaskFlow Web App

TaskFlow is a small React + Vite sample frontend for an AWS deployment study. It supports:

- Demo login
- Create task
- View tasks
- Update task status
- Delete task

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm install
npm run build
```

The production bundle is generated in `dist/`.

## Suggested AWS study focus

This app is intentionally frontend-only with local in-memory state so participants can focus on:

- Frontend hosting
- API integration design
- Authentication approach
- Deployment pipeline
- Monitoring and observability
